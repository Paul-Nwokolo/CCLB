# Porting the waterline redesign to WordPress

Handoff note for moving the `redesign/waterline` static site into WordPress.
Design intent and the visual system are in `DESIGN.md`. This file covers what exists,
where each thing lives, and what will break when it moves.

The site is plain static HTML, CSS and ES modules. No framework and no build step on the
host. The five HTML pages are generated by `tools/build_pages.py` (see "Regenerating the pages").

## 2. JavaScript behaviours

All site behaviour is in **`assets/js/main.js`** (one ES module, loaded with
`<script type="module">`), except the give page's own inline script. Function names are given
because line numbers drift.

| Behaviour | Where | Reads / depends on |
|---|---|---|
| **Boot flags** | inline `<script>` in every `<head>` | Adds `html.js`, `html.motion` (unless reduced motion), `html.arriving` (if `sessionStorage['cclb:arrive']`). Removes `motion`/`arriving` after 4 s if `window.__booted` was never set, so content can never stay hidden |
| **Smooth scroll** | `main.js`, top section | `window.Lenis` (vendor). Off under reduced motion and on pages with `<html data-native-scroll>` (harvest, join: next to the Tally iframes). Driven by GSAP's ticker |
| **Waterline** (signature) | `initSurfaces`, `waterTarget`, `apply`, `rippleTick`, `playIntro` | Each `[data-surface]` section (`home`, `inner`, `lost`). Rest height from CSS `--rest` via the `.surface__probe` element. Scroll progress from ScrollTrigger, scroll velocity for the ripple. Moves `[data-water]` and `[data-water-inner]` by transform only. CSS: "The surface" block in `site.css` |
| **Page transitions** | `initTransitions`, `finishArrival`, plus the head script | Intercepts clicks on same-origin links (skips `/admin`, `target=_blank`, downloads, modifier keys, same-page hashes, file links). Label from `data-dest` or link text. Sets `sessionStorage['cclb:arrive']` before navigating. Prefetches on hover. Resets on back/forward cache (`pageshow`). Markup: `#curtain` in every page |
| **Next Mass (Lagos time)** | `MASSES`, `lagosNow`, `initWeek` | `MASSES` array in `main.js` (Sun 8:30, Mon/Wed/Fri 6:30, Sat 8:00). Uses `Intl.DateTimeFormat` with `timeZone: 'Africa/Lagos'`. A Mass that began less than 50 minutes ago shows as "On now". Writes into `[data-next-mass]`. Static fallback text in the HTML is "Sunday, 8:30 AM". Public holidays are not modelled |
| **7-day timetable** | HTML in `index.html` (from `WEEK` in `tools/build_pages.py`), `initWeek` | The timetable itself is static HTML. JS only marks today: `[data-day]` 0 = Sunday ... 6 = Saturday, in Lagos time |
| **Forms lazy-load** | `initTally` | `iframe[data-tally-src]`. Loads `https://tally.so/widgets/embed.js` only when a form is within 600 px of the viewport, or when "Start the form" / "Make your commitment" is clicked. Falls back to setting `src` directly. Each embed has a visible "Open it in a new tab" link and a `noscript` link |
| **Header tone** | `initHeader` | `[data-tone="air|water|deep"]` on sections; for the hero it uses the live water height. Sets `html[data-under]`, `html.is-scrolled`, `html.header-away` (hides on scroll down) |
| **Mobile menu** | `initMenu` | `#menu` (dialog role), `[data-menu-open]`, `[data-menu-close]`. Traps Tab, Escape closes, restores focus |
| **Reveals** | `initReveals` | `[data-split]` (GSAP SplitText line masks), `[data-reveal]`. Skipped under reduced motion |
| **Gallery** | `initGallery` | Fetches **`/data/gallery.json`** (Decap CMS). Images open in the lightbox; ratio outside 1.3 to 2.4 switches to `contain`. YouTube items show a thumbnail from `https://i.ytimg.com/vi/<id>/hqdefault.jpg` and swap to the iframe on click. Hides the section if the feed is empty |
| **Lightbox** | `initLightbox` | Native `<dialog id="lightbox">`; triggers are `[data-lightbox="<src>"]` (gallery images, harvest posters) |
| **Copy to clipboard + toast** | `initCopy`, `toast` | `[data-copy="<text>"]`, optional `[data-copy-label]`; `#toast` |
| **Footer year** | `boot` | `[data-year]` |
| **Give page** | inline `<script>` at the end of `give/index.html` | The `CONFIG` object (below). Renders the fund list, account card, society picker, WhatsApp links, confirmation form, contact facts. Source: `tools/give_config.html` + `tools/give_render.js` |

Vendor scripts (`assets/js/vendor/`, loaded with `defer` **before** `main.js`, order matters):
`gsap.min.js` 3.13.0, `ScrollTrigger.min.js`, `SplitText.min.js` (GSAP standard no-charge
licence), `lenis.min.js` 1.3.4 (MIT). `main.js` reads them as globals (`window.gsap`, etc.).

## 6. Regenerating the pages

```
python tools/build_pages.py .
```
Python 3.8+, standard library only. Overwrites `index.html`, `404.html`, `give/index.html`,
`harvest/index.html`, `join/index.html`. The give page's `CONFIG` is read back from the
existing `give/index.html`, so committee edits survive a rebuild. Verified to reproduce the
committed pages byte for byte. For WordPress, the same file is the clearest map of the
markup to turn into templates.

## 7. What depends on Netlify

| Dependency | What it does now | In WordPress |
|---|---|---|
| `netlify.toml` redirects | `give.`, `harvest.`, `join.` subdomains 301 to `/give/`, `/harvest/`, `/join/` | Recreate at DNS / server level if the subdomains must keep working (they are on old QR codes and links) |
| `netlify.toml` security headers | HSTS, `X-Frame-Options: DENY`, `nosniff`, Referrer-Policy, Permissions-Policy, and a **Content-Security-Policy** | Recreate in the server or a security plugin. The CSP allows scripts only from `'self'` (plus inline and Tally). WordPress plugins usually load scripts from elsewhere, so the CSP will need rework |
| CSP and YouTube thumbnails | The gallery's YouTube thumbnails come from `https://i.ytimg.com`. The committed `netlify.toml` does **not** allow that host in `img-src`, so on Netlify those thumbnails are blocked (the play button still works) | Allow `https://i.ytimg.com` in `img-src`, or drop the thumbnail |
| Automatic `404.html` | Netlify serves `/404.html` with status 404 for unknown paths | Use the theme's `404.php` |
| Directory URLs | `/give/` resolves to `give/index.html` | WordPress permalinks |
| Decap CMS | `/admin/` with DecapBridge (git-gateway) commits `data/gallery.json` and `images/gallery/*` to `main` | Replace with WordPress media / a gallery post type; the gallery JS then needs a new data source |

No Netlify Forms are used. The give confirmation opens WhatsApp; the other forms are Tally.

## 8. What breaks if scripts or assets are not same-origin

The code assumes it is served from the site root of the same origin. Moving files under
`/wp-content/themes/<theme>/` or a CDN affects these:

1. **Absolute paths.** Every asset is referenced from the root: `/assets/css/site.css`,
   `/assets/js/...`, `/assets/fonts/...` (inside `site.css` too), `/assets/img/...`,
   `/harvest/...` posters, `/favicon.ico`, and the gallery feed `fetch('/data/gallery.json')`.
   All of these must be rewritten (for example with `get_theme_file_uri()`), including the
   `url()`s in `site.css`.
2. **ES module.** `main.js` is `type="module"`. Served from another origin, a module needs CORS
   headers (`Access-Control-Allow-Origin`) or it will not run. With `wp_enqueue_script`, add the
   `type="module"` attribute yourself (`wp_script_attributes` filter or `wp_enqueue_script_module`).
3. **Script order and timing.** `main.js` expects `gsap`, `ScrollTrigger`, `SplitText` and
   `Lenis` as globals, loaded with `defer` before it. Optimisation plugins that combine, delay or
   defer scripts ("delay JS until interaction") break this. The head script's 4-second fallback
   then removes `html.motion`, so content stays visible, but the waterline and transitions are lost.
4. **Inline scripts.** The head boot script, JSON-LD and the give page `CONFIG` script are
   inline. A CSP without `'unsafe-inline'` (or nonces) blocks them.
5. **Fonts from another origin.** Preloaded fonts use `crossorigin`. From a CDN or another
   domain they need `Access-Control-Allow-Origin`, or they are fetched twice or not at all.
6. **Page transitions.** They only intercept same-origin links and rely on `sessionStorage`,
   which is per origin. Within WordPress, add `/wp-admin`, `/wp-login.php` and any download or
   `?` query-string links to the exclusion list in `initTransitions`, or the curtain will play
   in front of them.
7. **Gallery feed.** `fetch('/data/gallery.json')` is same-origin. From another origin it needs
   CORS; in WordPress it is better replaced by a REST endpoint or server-rendered markup.
8. **Prefetch.** Hover prefetch adds `<link rel="prefetch">` for same-origin pages only. Harmless
   if it stops working.

Third-party origins in use today: `tally.so` (forms), `www.youtube.com` (video iframes),
`i.ytimg.com` (thumbnails), `images.unsplash.com` (two stock photos in the CMS gallery, to be
replaced with parish photos), `maps.google.com` and `wa.me` (outbound links only).
